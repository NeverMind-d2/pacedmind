---
title: Who does a task
description: The Done by field decides whether a task is yours or an agent's, and with it whether the task can run as an agent session and whether it fills your focus time.
---

Every task has someone who does it, set in the details panel under **Done by**:

| Choice | Meaning |
| --- | --- |
| **You** | Only you can do it (*No agent session*). |
| **Claude Code** | Claude Code works on it in a session. |
| **Codex** | Codex works on it in a session. |
| **Project default, Claude Code** (or **Codex**) | The project's default agent does it. Shown as **Not decided** when the project has no default agent. |

## What it changes

| | You | Claude Code or Codex | Project default or Not decided |
| --- | --- | --- | --- |
| Agent session | Can't start. The details panel shows *None, this one is yours*. | **Start with** that agent. | **Start with** the project's agent, or Claude Code when there is none. |
| Auto-planner | Planned into your focus time. | Left to the agent. When its session finishes, a 45-minute block to check the result is planned for you. | Planned into your focus time. |

Changing **Done by** also changes the picker beside **Agent** and the agent named on the new-session button. It applies to new sessions; the previous session keeps its original agent and conversation. To switch agents after stopping a session, choose the other agent and select **New session with Claude Code** (or **Codex**). **Resume Codex** or **Resume Claude Code** continues the original conversation. See [Switch agents](/tasks/task-details#switch-agents-after-a-session-ends).

## How it gets set

* **New tasks in a project** get the project's default agent. A project with Codex as its default agent creates tasks done by Codex.
* **New tasks elsewhere** start without a doer (**Not decided**).
* **Starting a session** sets the doer to the agent that runs it.
* **Agents** set it with `agent`: `claude`, `codex`, or `human` for you. `create_task` leaves it out for the project default; `update_task` takes `null` for that.
* **Changing a project's default agent** later affects new tasks and tasks set to the project default. Tasks created earlier keep the agent they were given.

## Your tasks and dependencies

Tasks that are yours can wait for other tasks too: a dependency drawn on the **Timeline** applies to them as to any task, and a task keeps its dependencies when it becomes yours. PacedMind never starts a session for them, so they wait for you to pick them up. See [Dependencies](/views/timeline#dependencies).
