The current version of PacedMind doesn't use an account. It keeps all data on one computer, in its own database. See [Where your data lives](/getting-started/data).

## What is planned

* **PacedMind on one computer stays as it is**: no account and no subscription.
* **Cloud data**, with a subscription: the planner's data stored in PacedMind Cloud, so the same tasks and plans are available on more than one device.
* **PacedMind accounts** for Cloud, with sign-in in the browser and in the desktop app.
* **A 7-day free trial** of Cloud.

Plans and prices are listed on the [PacedMind website](https://pacedmind.com/#pricing).

## When it's released

This page will then explain how to create an account and sign in, how existing data on the computer moves to Cloud, how devices stay in sync, and how to manage a subscription.
