The desktop app runs PacedMind's server and shows the planner in a window. It keeps running in the tray when the window is closed, so agents can report back at any time.

## The window

* The window remembers its size, its position and whether it was maximized. It opens at 1440 × 900 the first time and can't be made smaller than 960 × 600.
* The title bar is PacedMind's header: the **Go back** and **Go forward** buttons, the wordmark, and the window's own minimize, maximize and close buttons. Drag the empty part of the header to move the window.
* The mouse's back and forward buttons also move through the views.
* The title bar follows the dark or light theme.
* Links to other websites open in the default browser.
* Opening PacedMind while it's already running brings the existing window to the front instead of starting a second copy.

While the server starts, the window shows *Starting PacedMind…*.

## Closing and quitting

Closing the window, with its **×** button or <kbd>Ctrl</kbd>+<kbd>W</kbd>, hides it; PacedMind keeps running in the tray. The first time, a notification titled *PacedMind is still running* explains: *It stays in the tray so agents can report back. Right-click the icon to quit.*

To quit, right-click the tray icon and select **Quit PacedMind**, or press <kbd>Ctrl</kbd>+<kbd>Q</kbd> in the window. Quitting stops the server: agents can't reach PacedMind, and so can't report back, until it runs again.

## The tray icon

Click the tray icon to open the window. Its tooltip reads *PacedMind*, or *PacedMind · 2 waiting for you* when finished sessions wait for review.

Right-click it for the menu:

| Item | Result |
| --- | --- |
| **Open PacedMind** | Opens the window. |
| **Start with Windows** | When checked, PacedMind starts when you sign in to Windows, in the tray, without opening the window. |
| **Open data folder** | Opens `%APPDATA%\Organizer\data` in File Explorer. |
| **Open server log** | Opens the server's log file. |
| **Quit PacedMind** | Stops the app and its server. |

## Notifications

When an agent finishes a session, PacedMind shows a Windows notification: *DEV-21 is finished*, with the task's title and the agent's note. Click it to open the session in **Sessions**. PacedMind checks for finished sessions every five seconds while it runs. Sessions that were already waiting when PacedMind started don't get a notification; the tray tooltip and the **Sessions** count include them.

Notifications follow Windows' own settings. If none appear, check that notifications for PacedMind are on in Windows **Settings → System → Notifications**, and that Do not disturb (Focus assist on Windows 10) is off.

## The server

The app runs its server at `http://127.0.0.1:4319`, reachable only from the same computer. It writes a log to `%APPDATA%\Organizer\logs\server.log` (tray menu → **Open server log**).

If the server can't start, a dialog says *PacedMind could not start.* and asks whether something else uses port 4319, with **Try again**, **Open log** (which opens the log and closes PacedMind) and **Quit**. If it stops while the app runs, a dialog says *PacedMind's server stopped.*, with **Restart**, **Open log** (which opens the log and restarts the server) and **Quit**. See [Troubleshooting](/troubleshooting#pacedmind-could-not-start).

## Keyboard shortcuts in the window

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the window (PacedMind stays in the tray). |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit PacedMind. |
| <kbd>Alt</kbd>+<kbd>Left</kbd>, <kbd>Alt</kbd>+<kbd>Right</kbd> | Back and forward. |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Reload the view. |
| <kbd>Ctrl</kbd>+<kbd>+</kbd>, <kbd>Ctrl</kbd>+<kbd>-</kbd>, <kbd>Ctrl</kbd>+<kbd>0</kbd> | Zoom in, zoom out, reset the zoom. |
| <kbd>F11</kbd> | Full screen. |

All shortcuts are on the [Keyboard shortcuts](/keyboard-shortcuts) page.

## Updating and uninstalling

Run `npm run desktop` again in the source folder to update; the data stays. To uninstall, remove the shortcuts with `Organizer.exe --uninstall` and delete the installation folder. See [Install PacedMind](/getting-started/install#update).
