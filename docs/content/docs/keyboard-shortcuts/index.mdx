---
title: Keyboard shortcuts
description: Every keyboard shortcut in PacedMind, everywhere in the app, in quick add, an activity and the command menu, in lists and task details, the image viewer and the calendar, and in the desktop window.
---

On a Mac, <kbd>⌘</kbd> works in place of <kbd>Ctrl</kbd> for <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>Ctrl</kbd>+<kbd>B</kbd> and <kbd>Ctrl</kbd>+<kbd>Enter</kbd>, and the desktop window has the Mac's own shortcuts ([below](#desktop-window)).

## Everywhere

| Keys | Action |
| --- | --- |
| <kbd>C</kbd> | New task (quick add). Works when the cursor isn't in a text field. |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open or close the command menu. |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Hide or show the sidebar. On a phone, open or close it. |
| <kbd>Esc</kbd> | Close the task's details panel, a menu or a dialog. |
| <kbd>Alt</kbd>+<kbd>Left</kbd> (macOS app: <kbd>⌘</kbd>+<kbd>[</kbd>) | Go back. |
| <kbd>Alt</kbd>+<kbd>Right</kbd> (macOS app: <kbd>⌘</kbd>+<kbd>]</kbd>) | Go forward. |

## Quick add

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Create the task or the activity (from the title). |
| <kbd>Enter</kbd>, in the **Done when** field | Start a new line, for the next item. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Create it from anywhere in the dialog, including the description and the **Done when** field. |
| <kbd>Esc</kbd> | Close the dialog. |

## Activity

The dialog that opens with a click on an activity.

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd>, in the title | Save the changes. |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Save them from anywhere in the dialog. |
| <kbd>Esc</kbd> | Close the dialog without saving. |

## Command menu

| Keys | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the entries. |
| <kbd>Enter</kbd> | Open the highlighted entry. |
| <kbd>Esc</kbd> | Close the menu. |

## Tasks and names

| Where | Keys | Action |
| --- | --- | --- |
| Task title, in the details panel | <kbd>Enter</kbd> | Save the title. |
| A task's description, in the details panel or quick add | <kbd>Ctrl</kbd>+<kbd>B</kbd> / <kbd>Ctrl</kbd>+<kbd>I</kbd> | Make the selection bold / italic. |
| A link in a task's description | <kbd>Ctrl</kbd>-click | Open the link. |
| **+ Add** (labels) | <kbd>Enter</kbd> | Add the label. |
| **+ Add sub-task** | <kbd>Enter</kbd> | Add the sub-task. |
| **+ Add what must be true when it's done** (the **Done when** list) | <kbd>Enter</kbd> | Add the item. |
| A **Done when** item, in the details panel | <kbd>Enter</kbd> | Save the item. |
| The **Request changes** box | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> / <kbd>Esc</kbd> | Send the changes to the agent / close the box. |
| Renaming an area or a project, or naming a new one | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Save / cancel. |
| A confirmation dialog | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Confirm / cancel. |
| The **Roadmap**'s **Folder** field | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Save / undo the edit. |

## Image viewer

The viewer opens from a screenshot in an agent's report, in the task's details or in **Sessions**.

| Keys | Action |
| --- | --- |
| <kbd>←</kbd> <kbd>→</kbd> | Previous or next image, when there are several. |
| <kbd>Esc</kbd> | Close the viewer. |
| A click on the image | Show it at its actual size, or fit it to the window again. |
| A click beside the image | Close the viewer. |

## Calendar

| Keys | Action |
| --- | --- |
| <kbd>Tab</kbd> to a task, then <kbd>Enter</kbd> or <kbd>Space</kbd> | Month view: open the task's menu. Week view: open the task's details. |
| <kbd>Tab</kbd> to an activity, then <kbd>Enter</kbd> or <kbd>Space</kbd> | Open the activity, to change or delete it. |
| <kbd>Esc</kbd> | Close a day opened with **+3 more**, the menu, or the task's details. |

## Desktop window

| Windows | macOS | Action |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | <kbd>⌘</kbd>+<kbd>W</kbd> | Close the window. PacedMind keeps running in the tray or the menu bar. |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | <kbd>⌘</kbd>+<kbd>Q</kbd> | Quit PacedMind. |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | <kbd>⌘</kbd>+<kbd>R</kbd> | Reload the view. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | <kbd>⌘</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reload, ignoring the cache. |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | <kbd>⌘</kbd>+<kbd>+</kbd> | Zoom in. |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | <kbd>⌘</kbd>+<kbd>-</kbd> | Zoom out. |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | <kbd>⌘</kbd>+<kbd>0</kbd> | Reset the zoom. |
| <kbd>F11</kbd> | <kbd>Ctrl</kbd>+<kbd>⌘</kbd>+<kbd>F</kbd> | Full screen. |
| Mouse back and forward buttons | The same, or a three-finger swipe | Go back and forward. |

The usual editing shortcuts, such as <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>+<kbd>A</kbd> (with <kbd>⌘</kbd> on a Mac), work in every text field.
