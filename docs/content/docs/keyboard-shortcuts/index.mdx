---
title: Keyboard shortcuts
description: Every keyboard shortcut in PacedMind, everywhere in the app, in quick add and the command menu, in lists, the calendar and the flow editor, and in the desktop window.
---

On a Mac keyboard, <kbd>Cmd</kbd> works in place of <kbd>Ctrl</kbd> for <kbd>Ctrl</kbd>+<kbd>K</kbd> and <kbd>Ctrl</kbd>+<kbd>Enter</kbd>.

## Everywhere

| Keys | Action |
| --- | --- |
| <kbd>C</kbd> | New task (quick add). Works when the cursor isn't in a text field. |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Open or close the command menu. |
| <kbd>Esc</kbd> | Close the task's details panel, a menu or a dialog. |
| <kbd>Alt</kbd>+<kbd>Left</kbd> | Go back. |
| <kbd>Alt</kbd>+<kbd>Right</kbd> | Go forward. |

## Quick add

| Keys | Action |
| --- | --- |
| <kbd>Enter</kbd> | Create the task or the activity (from the title). |
| <kbd>Ctrl</kbd>+<kbd>Enter</kbd> | Create it from anywhere in the dialog, including the description. |
| <kbd>Esc</kbd> | Close the dialog. |

## Command menu

| Keys | Action |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move through the entries. |
| <kbd>Enter</kbd> | Open the highlighted entry. |
| <kbd>Esc</kbd> | Close the menu. |

## Tasks and names

| Where | Keys | Action |
| --- | --- | --- |
| Task title, in the details panel | <kbd>Enter</kbd> | Save the title. |
| **+ Add** (labels) | <kbd>Enter</kbd> | Add the label. |
| **+ Add sub-task** | <kbd>Enter</kbd> | Add the sub-task. |
| Renaming an area or a project, or naming a new one | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Save / cancel. |
| A confirmation dialog | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Confirm / cancel. |
| The **Roadmap**'s **Folder** field | <kbd>Enter</kbd> / <kbd>Esc</kbd> | Save / undo the edit. |

## Calendar

| Keys | Action |
| --- | --- |
| <kbd>Tab</kbd> to a task, then <kbd>Enter</kbd> or <kbd>Space</kbd> | Month view: open the task's menu. Week view: open the task's details. |
| <kbd>Esc</kbd> | Close a day opened with **+3 more**, the menu, or the task's details. |

## Flow editor

| Keys | Action |
| --- | --- |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Remove the selected session from the flow, or the selected connection. |
| <kbd>Esc</kbd> | Clear the selection. |
| Mouse wheel or touchpad scroll | Pan the canvas. |
| <kbd>Ctrl</kbd> + mouse wheel, or a pinch on a touchpad | Zoom the canvas. |
| <kbd>Enter</kbd>, in the **At a set time** field | Save the time. |

## Desktop window

| Keys | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the window. PacedMind stays in the tray. |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit PacedMind. |
| <kbd>Ctrl</kbd>+<kbd>R</kbd> | Reload the view. |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reload, ignoring the cache. |
| <kbd>Ctrl</kbd>+<kbd>+</kbd> | Zoom in. |
| <kbd>Ctrl</kbd>+<kbd>-</kbd> | Zoom out. |
| <kbd>Ctrl</kbd>+<kbd>0</kbd> | Reset the zoom. |
| <kbd>F11</kbd> | Full screen. |
| Mouse back and forward buttons | Go back and forward. |

The usual editing shortcuts, such as <kbd>Ctrl</kbd>+<kbd>C</kbd>, <kbd>Ctrl</kbd>+<kbd>V</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd> and <kbd>Ctrl</kbd>+<kbd>A</kbd>, work in every text field.
