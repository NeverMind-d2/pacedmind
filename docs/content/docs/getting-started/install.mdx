---
title: Install PacedMind
description: Build the PacedMind desktop app from its source code, install it for the current Windows user, update it, and uninstall it.
---

PacedMind is built from its source code and installed with one command. The installation is per user: it goes into the user's own program folder, adds shortcuts, and doesn't ask for administrator rights.

## Before installing

* Windows 10 or Windows 11.
* [Git](https://git-scm.com/) and [Node.js](https://nodejs.org/) 22.13 or later. Node.js includes npm.

Claude Code, Codex and Windows Terminal aren't needed for the installation. They matter once PacedMind starts agent sessions; see [Agent sessions](/agents).

## Install

1. Open a terminal (Windows Terminal or PowerShell) in the folder that should hold the source code.
2. Download the source code and go into its folder:

   ```powershell
   git clone https://github.com/NeverMind-d2/pacedmind.git
   cd pacedmind
   ```

3. Install the dependencies:

   ```powershell
   npm install
   ```

4. Build and install the desktop app:

   ```powershell
   npm run desktop
   ```

`npm run desktop` takes a few minutes. It:

* builds the app and packages it with Electron;
* closes PacedMind if it is running from an earlier installation;
* installs it to `%LOCALAPPDATA%\Programs\Organizer`;
* adds **PacedMind** to the Start Menu and to the desktop;
* starts PacedMind.

The last line of its output names the data folder, `%APPDATA%\Organizer` (for example `C:\Users\Anna\AppData\Roaming\Organizer`). The first start creates an empty database with five default areas. See [First launch](/getting-started/first-launch).

### Why some names say Organizer

Organizer is PacedMind's earlier name. The installation folder, the executable (`Organizer.exe`), the data folder and the MCP server's identifier (`organizer`) keep that name, so updates keep the existing data and agent connections. Windows shows the app, its shortcuts and its notifications as **PacedMind**; the **Details** tab of Task Manager lists its processes as `Organizer.exe`.

### Other options

| Command | Result |
| --- | --- |
| `npm run desktop` | Builds, installs and starts the app. |
| `npm run desktop -- --no-launch` | Builds and installs the app without starting it. |
| `npm run desktop -- --no-install` | Builds and packages the app into `dist\package` without installing it. |

The desktop app is built for Windows. On other operating systems, `npm run desktop` packages the app into `dist/package` and doesn't install it.

## Update

1. In the source folder, get the latest code:

   ```powershell
   git pull
   npm install
   ```

2. Run the installation again:

   ```powershell
   npm run desktop
   ```

The command closes the running app, replaces it and starts the new version. The data in `%APPDATA%\Organizer` stays as it is, including the MCP access token, so connected agents keep working.

If the running app can't be closed, the command stops with *Organizer is still running. Quit it from the tray icon and run this again.* Quit PacedMind from its tray icon (**Quit PacedMind**) and run `npm run desktop` again.

## Uninstall

1. Quit PacedMind: right-click its tray icon and select **Quit PacedMind**.
2. Remove the shortcuts and the **Start with Windows** entry:

   ```powershell
   & "$env:LOCALAPPDATA\Programs\Organizer\Organizer.exe" --uninstall
   ```

3. Delete the folder `%LOCALAPPDATA%\Programs\Organizer`.
4. To delete the data as well, delete the folder `%APPDATA%\Organizer`. This removes every area, project, task, activity and session record, and can't be undone.

If Claude Code or Codex were connected to PacedMind, remove those connections too:

* Claude Code: `claude mcp remove organizer` (add `--scope user` if it was added for all projects).
* Codex: delete the `[mcp_servers.organizer]` section from `~/.codex/config.toml`.
* Agent skills: `npm run skills -- --remove` in the source folder. See [Agent skills](/skills).

## Troubleshooting

* **The build fails on an older Node.js:** check the version with `node --version`. PacedMind needs 22.13 or later, which runs its database module without extra flags. `npm install` only warns about an older version; `npm run desktop` then fails.
* **The installation stops at "Organizer is still running":** quit PacedMind from the tray and run the command again.
* **PacedMind was installed from a terminal inside the Claude or Codex desktop app, and its data or icon looks wrong:** those apps keep a separate copy of `AppData` for the programs they start. Open PacedMind from the Start Menu instead. See [Troubleshooting](/troubleshooting#the-data-looks-empty-or-the-icon-is-blank).

More problems and their solutions are on the [Troubleshooting](/troubleshooting) page.
