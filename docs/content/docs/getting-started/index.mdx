PacedMind is a desktop app for Windows. It runs its own small server on the computer, shows the planner in its window, and keeps all data in one database file in the user's profile. Claude Code and Codex connect to the same server to read tasks and to report on the sessions PacedMind starts for them.

Getting started takes three steps: install the app, open it and set up the basics, and, optionally, connect the agents.

## Prerequisites

* **Windows 10 or Windows 11.** The app installs for the current Windows user and doesn't need administrator rights.
* **Git** and **Node.js 22.13 or later** (with npm), to build the app from its source code.
* For agent sessions, optionally:
  * **Claude Code** and/or **Codex**, installed and signed in, so that the `claude` and `codex` commands work in a terminal;
  * **Windows Terminal**, which PacedMind uses by default to open sessions. Without it, sessions open in a Command Prompt window.
