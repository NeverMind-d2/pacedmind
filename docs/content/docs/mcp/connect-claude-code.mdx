---
title: Connect Claude Code
description: Register PacedMind's MCP server in Claude Code, for the Claude app and the sessions you start yourself, check the connection, and update it after a new token.
---

Claude Code sessions that PacedMind starts in a terminal are connected automatically. For sessions in the Claude app, and Claude Code sessions you start yourself, register PacedMind's MCP server once, for all projects: the Claude app's Code sessions use the same registration.

## With Connect in Settings

In **Settings → MCP server**, under **Connect your agents**, select **Connect** next to **Claude Code** and confirm. PacedMind replaces an earlier registration for all projects, under the name `pacedmind` or PacedMind's earlier name `organizer`, with one for this PacedMind, with the current token, without showing it (*Connected Claude Code for all your projects. New Claude Code sessions can use PacedMind.*). **Computers** then shows Claude Code as *Connected*.

## With the command from Settings

1. Open **Settings → MCP server** and, under **Connect your agents**, select **Copy command** next to **Claude Code**. The command contains the address and the access token:

   ```powershell
   claude mcp add --transport http --scope user pacedmind http://127.0.0.1:4319/api/mcp --header "Authorization: Bearer org_..."
   ```

2. Paste it into a terminal and run it.

The command registers PacedMind for all projects (`--scope user`). Without `--scope user`, it would register PacedMind only for the project folder the terminal is in, Claude Code's default.

Keep the name `pacedmind`: PacedMind's skills and the sessions it starts refer to the server by that name. A registration under the earlier name, `organizer`, still works, and **Computers** shows it as *Old name*; **Connect** replaces it. Before running the command, remove it with `claude mcp remove organizer --scope user`.

## With npm run connect

From PacedMind's source folder, `npm run connect` says where to connect: **Connect** in the app, which hands Claude Code the token without showing it, so no other program on the computer can read it. `npm run connect -- --remove` removes the registration for all projects, under either name.

A registration made for one project folder with the copied command stays as it is, and takes precedence in that folder: remove it with `claude mcp remove pacedmind`, or `claude mcp remove organizer` for one under the earlier name, run in that folder.

## Check the connection

* In a terminal, `claude mcp list` lists `pacedmind` with its state.
* In Claude Code, `/mcp` shows the server and its tools.

The tools appear in Claude Code as `mcp__pacedmind__` followed by the tool name, such as `mcp__pacedmind__get_overview`. Claude Code asks for approval the first time a session uses each tool, unless the tool is allowed in its settings.

Ask something that needs the planner to try it, such as *What's on my plate today in PacedMind?* With the [agent skills](/skills) installed, Claude Code also knows how to plan, triage and set up projects with the tools.

## After regenerating the token

A new token in **Settings → MCP server** disconnects Claude Code until it has the new one:

1. Remove the old registration with `claude mcp remove pacedmind`, adding `--scope user` if it was registered for all projects.
2. Run the updated command from **Settings → MCP server**.

For a registration made for all projects, **Connect** in **Settings → MCP server** does both steps at once.

## Remove the connection

```powershell
claude mcp remove pacedmind
```

Add `--scope user` when it was registered for all projects. A registration under the earlier name is removed with `claude mcp remove organizer`.

## Problems

* **`claude mcp list` shows the server as failed**: PacedMind isn't running, the port is wrong (4319 for the desktop app, 4320 for a development copy), or the token changed. Start PacedMind and register it again.
* **The tools don't appear in a project**: the server was registered for another project folder. Register it with `--scope user`.

More in [Troubleshooting](/troubleshooting#an-agent-cant-reach-pacedmind).
