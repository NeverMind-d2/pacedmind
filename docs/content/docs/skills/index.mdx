---
title: Agent skills
description: Five skills that teach Claude Code and Codex to use PacedMind's MCP tools well, from quick changes to planning, project setup, reviews and working on a task. Install them with npm run skills.
---

The MCP server gives an agent the tools; the **skills** tell it how to use them well. A skill is a short set of instructions that Claude Code or Codex loads when a request matches it, even when the request doesn't mention PacedMind. For example, *plan my week* loads the planning skill.

## The five skills

| Skill | Used when | What it does |
| --- | --- | --- |
| **pacedmind** | Adding, finding, changing, completing or deleting tasks, projects, areas or activities; asking what's on the plate. | The basics: how the planner is organized, how to refer to things, how to write tasks someone can act on weeks later, and what to ask before doing. |
| **pacedmind-planning** | *What should I work on?*, *plan today*, *move X to Friday*, *clear my afternoon*, *I'm sick today*, feeling overloaded. | Reads the agenda, proposes a plan, and moves tasks and activities only with your agreement. Explains how focus blocks are made. |
| **pacedmind-projects** | Starting something new, asking for a breakdown, a roadmap or milestones, or wanting agents to work through a project. | Creates the project, breaks it into well-described tasks with sub-tasks and estimates, orders the roadmap, sets dates and dependencies between projects, and wires agent flows. |
| **pacedmind-review** | Triage, clean-up, catching up, *what's overdue*, a weekly review. | Goes through the Inbox, overdue and stale tasks, and sessions waiting for review, in small batches with a suggested decision for each. |
| **pacedmind-agent-session** | The agent's first message names a PacedMind task and session, or it's asked to work on a PacedMind task. | The protocol for working on a task: `start_task`, keeping sub-tasks current, recording follow-up tasks, and handing back with `finish_task`. |

The **pacedmind** skill tells the agent to ask before deleting anything and before starting agent sessions, and not to mark a task done that an agent worked on unless you say you reviewed it. The MCP server gives every agent the first two rules too, with or without the skills.

## Install the skills

The skills ship in PacedMind's source code, in the `skills` folder. From the source folder, run:

```powershell
npm run skills
```

The command copies the five skills into:

* `~/.claude/skills` for Claude Code, when Claude Code is installed (when the `~/.claude` folder exists);
* `~/.codex/skills` for Codex, when Codex is installed (when the `~/.codex` folder exists).

It replaces earlier copies of these five skills and leaves other skills alone. Start a new Claude Code or Codex session to pick them up. Run the command again after updating PacedMind's source, so the skills match the tools.

To uninstall them:

```powershell
npm run skills -- --remove
```

## Before using them

The skills need the MCP server connected in the agent: see [Connect Claude Code](/mcp/connect-claude-code) and [Connect Codex](/mcp/connect-codex). Without it, the agent says that PacedMind's tools aren't available and points to PacedMind's settings; the commands to connect are under **Settings → Connect your agents**.

The skills tell agents to use the tools rather than PacedMind's files or database: flows, notifications and the open views only react to changes made through the tools.

## Examples

* *Add a task to renew the car insurance before October 10, high priority.* The **pacedmind** skill creates it with a description, a due date and an estimate, and reports the key and the resolved date.
* *Plan my Thursday.* The **pacedmind-planning** skill reads the agenda, suggests what fits in the free focus time, and changes planned days after you agree.
* *I want to build a recipe app with Claude Code.* The **pacedmind-projects** skill sets up the project, breaks it into tasks with acceptance criteria, and offers a flow.
* *Let's do the weekly review.* The **pacedmind-review** skill walks through the Inbox, overdue tasks, finished sessions and upcoming deadlines.
* In a session PacedMind started, the **pacedmind-agent-session** skill makes the agent pick up the task, tick off sub-tasks, and hand it back with a note.
